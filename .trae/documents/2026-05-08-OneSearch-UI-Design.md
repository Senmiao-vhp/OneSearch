## 1. 设计概述

重新设计OneSearch前端界面，提供统一的搜索入口，支持四个数据源（CSDN、知网、GitHub、Gitee）并行搜索，通过Tab切换显示不同平台结果。

## 2. 交互流程

```
1. 用户在搜索框输入关键词
2. 点击搜索按钮或按回车
3. 前端同时触发4个数据源搜索（并行请求）
4. 结果预加载到状态管理器
5. 用户切换Tab，内容区即时显示对应平台结果
```

## 6. 技术实现

### 6.1 状态管理（Zustand）

```typescript
interface SearchState {
  query: string;
  activeTab: 'all' | 'github' | 'csdn' | 'gitee' | 'cnki';
  results: {
    github: SearchResult[];
    csdn: SearchResult[];
    gitee: SearchResult[];
    cnki: SearchResult[];
  };
  loading: {
    github: boolean;
    csdn: boolean;
    gitee: boolean;
    cnki: boolean;
  };
  setQuery: (query: string) => void;
  setActiveTab: (tab: string) => void;
  searchAll: () => Promise<void>;
}
```

### 6.2 并行搜索实现

```typescript
const searchAll = async () => {
  const [github, csdn, gitee, cnki] = await Promise.all([
    searchGithub(query),
    searchCsdn(query),
    searchGitee(query),
    searchCnki(query),
  ]);
  setResults({ github, csdn, gitee, cnki });
};
```
